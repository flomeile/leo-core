# gesperrte-pfade.txt
# Ordner und Dateien, die der Agent NIE lesen darf, weil ihr Inhalt nach deinen
# Datenregeln in keine Cloud-KI gehoert (Kundenkonfigurationen, Exporte unter NDA,
# Gesundheitsdaten, alles, was ein Kunde dir anvertraut hat).
#
# Eine Angabe je Zeile, absolut. ~ steht fuer dein Benutzerprofil. Zeilen mit # sind
# Kommentar. Gross/Klein spielt unter Windows keine Rolle. Ein Eintrag sperrt den Pfad
# und alles darunter.
#
# Durchgesetzt von 00_INDEX\scripts\guard-read.ps1 (AGENTS.md, Abschnitt 18). Zugangsdaten
# (.env, Schluesseldateien, .ssh, .aws, Token-Dateien) sind dort fest eingebaut und
# muessen hier nicht stehen.
#
# Diese Datei gehoert dir (Kern-Dateien.md, Kategorie B): Ein Update des Grundgeruests
# ersetzt sie nie. Der Agent erweitert oder kuerzt sie nie von sich aus; ein Eintrag
# kommt oder geht nur durch dich.
#
# Beispiele (auskommentiert):
# C:\Kunden
# ~\Projekte\Kunde-A\config
# /Users/DEIN-NAME/Kunden
